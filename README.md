# Site — Dra. Nicole Almeida · Odontologia · Campinas–SP

Site institucional da Dra. Nicole Almeida (prótese e reabilitação oral).

## Estrutura

```
brand/            Identidade visual pronta para web
  logo/           Logos vetoriais (SVG, cor via currentColor): completo, horizontal, monograma
  fonts/          Arsenal SC (TTF originais, licença OFL)
conteudo/         Textos fornecidos pelo cliente (serviços, endereço)
design-options/   Conceitos de design da home (fase de escolha)
  _shared/        Assets otimizados usados pelos conceitos (fotos WebP, fontes WOFF2, logos, vídeo) + BRIEF.md
  opcao-N-*/      Cada conceito: index.html autocontido
pesquisa/         Pesquisa de referências, SEO/IA, conformidade CFO e tecnologia
_originais/       (fora do git) fotos em alta, vídeo, arquivos .ai/.pdf e brand book interno
```

## Ver os conceitos localmente

```bash
python -m http.server 8787
```

Abra http://localhost:8787/design-options/
